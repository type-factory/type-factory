
These zip archives get unzipped into the `target/classes` directory during the build process. The `ucd.all.grouped.zip` file contains the Unicode Character Database (UCD) data, while the `cldr-common-*.zip` files contain the Unicode Common Locale Data Repository (CLDR) data.

Versioned releases of the Unicode dataset (for `ucd.all.grouped.zip`) can be downloaded from:

- see all versions https://www.unicode.org/Public/
- specific version https://www.unicode.org/Public/17.0.0/ucdxml/

Versioned releases of the Unicode CLDR dataset (for `cldr-common-*.zip`) can be downloaded from:

- https://cldr.unicode.org/index/downloads
